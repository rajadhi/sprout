## Problem

Signal-derived drafts (REQ-001) will sometimes be wrong — a photo location misidentified, a
calendar event misinterpreted. The user has no way to fix this today.

## Desired outcome

The user can edit any generated draft entry directly, and their edit persists as the entry's
content going forward — the system does not regenerate over a user's correction.

## Scope

Text editing of the draft. Re-associating or removing individual signal references (e.g. "this
wasn't actually a photo from today").

## Non-goals

Teaching the generation model from corrections (personalization) — future requirement if ever.

## Acceptance criteria

- AC-002-01: Given a generated draft entry, when the user edits its text and saves, then
  reopening the entry shows the edited text, not the original generation.
- AC-002-02: Given an edited entry, when the same day's signals are later reprocessed for any
  reason, then the user's edit is not overwritten.
