# Working in this repository

This project uses Sprout. Canonical product/engineering state lives in `.sprout/` and the
artifact tree (`requirements/`, `designs/`, `architecture/`, `tasks/`, `verification/`,
`evidence/`) — not in chat history, not in GitHub issue text once those exist.

Use `/sprout:shape` to turn new thoughts (drop raw notes in `thoughts/`) into structured,
approved requirements. Use `/sprout:status` for current state. See the Sprout plugin's own
`docs/getting-started.md` for the full command walkthrough.
